# Trabalho de Programacao - Java Web

Sistema desenvolvido para o 3 semestre da faculdade. O objetivo e fazer o cadastro de livros utilizando servlets e jsp.

Integrantes do grupo:
- Giovani Nunes Marques Luiz
- Adrienne Xavier de Carvalho

Funcionalidades:
- Cadastro de livros
- Listagem dos livros cadastrados
- Alterar dados de um livro
- Excluir um livro

Classe Livro:
- id
- nomeLivro
- isbn
- autor
- dataPublicacao
- valorLivro

Tecnologias:
- Java
- Servlets e JSP
- PostgreSQL
- Maven

Banco de dados:
O sistema cria o banco biblioteca e a tabela livros_tb automaticamente se nao existirem. As configuracoes estao no arquivo Conexao.java.
